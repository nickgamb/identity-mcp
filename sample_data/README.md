# Sample Data

Fictional conversation and memory data for trying identity-mcp without your own data.

## Persona

**Morgan Riley** -- platform engineer at a fintech company. Writes Go and Python,
builds event-driven microservices, bakes sourdough, tinkers with Home Assistant /
ESPHome / Zigbee, and trains for ultramarathons.

The persona has a distinctive writing style the identity model can learn:
em-dashes, "the thing is", "fundamentally", systems-thinking analogies across
domains, concise and precise phrasing.

## Contents

- `conversations.json` -- ChatGPT export format (25 conversations, tree structure)
- `conversations/` -- 25 pre-parsed JSONL files (~107 user messages)
- `memory/memories.json` -- 70 ChatGPT-style memory entries

## Usage

### Option A: Full pipeline (recommended)

Upload `conversations.json` through the dashboard or copy it manually, then run
the full processing pipeline:

```bash
# From the project root
cp sample_data/conversations.json conversations/conversations.json
cp sample_data/memory/memories.json memory/memories.json
```

Then from the dashboard or CLI:

1. **Parse conversations**: Run `parse_conversations` to convert the ChatGPT
   export into per-conversation JSONL files.
2. **Parse memories**: Run `parse_memories` to generate `memory/user.context.jsonl`.
3. **Analyze patterns**: Run `analyze_patterns` to discover keywords and topics.
4. **Train identity model**: Run `train_identity_model` to build the behavioral
   fingerprint.

### Option B: Skip parsing

If you want to skip the parsing step, copy the pre-parsed JSONL files directly:

```bash
cp sample_data/conversations/*.jsonl conversations/
cp sample_data/memory/memories.json memory/memories.json
```

Then run `train_identity_model` directly.

### Verify

Send a message in Morgan's style and verify it scores high confidence. Send an
unrelated message and verify it scores low.

## Regenerating

The data is generated by `generate_sample_data.py`. Run it to regenerate with
fresh UUIDs and timestamps:

```bash
python sample_data/generate_sample_data.py
```

## Notes

- This data is entirely fictional. No real person's data was used.
- 107 user messages across 25 conversations is enough to train a basic identity
  model but is smaller than a typical real dataset. The model will work but
  confidence scores may be lower than with hundreds of conversations.
- The conversations directory uses `.jsonl` format (one JSON object per line)
  matching the project's expected format.
- The memories file matches the ChatGPT memory export format.
